# Система мониторинга скорости перемешивания (температура пара)

## Описание проекта
Программа предназначена для мониторинга технологического процесса в реакторе. Она преобразует измеряемые значения параметра X (температура пара / скорость перемешивания) в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и готовит базу для статистического анализа выборки.

## Входные данные
- **Параметр X**: температура пара (или скорость перемешивания), измеряется в условных единицах.
- **Диапазон X**: любое вещественное число. 
- **Обоснование корректности формулы на всех участках**: 
  - При $X < 140$ используется квадрат разности, что всегда даёт неотрицательное число.
  - При $140 \le X \le 180$ подкоренное выражение $(X - 140) \ge 0$, поэтому квадратный корень извлекается корректно.
  - При $X > 180$ используется линейная функция, не имеющая математических ограничений.

## Формула преобразования Q(X)
Расчёт показателя качества производится по следующей кусочно-заданной функции:

$$
Q(X) = \begin{cases} 
\frac{(X - 140)^2}{18} + 8, & \text{при } X < 140 \\
2 \cdot \sqrt{X - 140} + 42, & \text{при } 140 \le X \le 180 \\
3 \cdot (X - 180) + 60, & \text{при } X > 180 
\end{cases}
$$

*(Примечание: в исходном задании вторая ветвь записана как $\sqrt{X - 160 + 20}$, что математически тождественно $\sqrt{X - 140}$. В коде использован упрощённый вид для улучшения читаемости и соответствия данному README).*

## Ручной расчёт (Примеры)
1. **X = 100** (условие $X < 140$):  
   $Q = \frac{(100 - 140)^2}{18} + 8 = \frac{1600}{18} + 8 \approx 88.8889 + 8 = 96.8889$

2. **X = 165** (условие $140 \le X \le 180$):  
   $Q = 2 \cdot \sqrt{165 - 140} + 42 = 2 \cdot \sqrt{25} + 42 = 2 \cdot 5 + 42 = 52.0000$

3. **X = 200** (условие $X > 180$):  
   $Q = 3 \cdot (200 - 180) + 60 = 3 \cdot 20 + 60 = 60 + 60 = 120.0000$
