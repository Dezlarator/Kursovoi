Система мониторинга температуры пара в реакторе

Постановка задачи

Программа предназначена для мониторинга технологического процесса в реакторе по параметру «температура пара» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.

Входные данные:

- Параметр X: температура пара, измеряется в условных единицах (или °C).
- Диапазон X: любое вещественное число. Функция корректно определена для всех X, так как при X < 140 используется квадрат разности, при 140 ≤ X ≤ 180 подкоренное выражение (X - 140) ≥ 0, а при X > 180 используется линейная функция.
- Количество измерений в выборке: N (задается в рамках полного задания).

Формула преобразования Q(X):

$$
Q(X) = \begin{cases} 
\frac{(X - 140)^2}{18} + 8, & \text{при } X < 140 \\
2 \cdot \sqrt{X - 140} + 42, & \text{при } 140 \le X \le 180 \\
3 \cdot (X - 180) + 60, & \text{при } X > 180 
\end{cases}
$$

Ручной расчет (Примеры):

1. **X = 100** (меньше 140):  
   $Q = \frac{(100 - 140)^2}{18} + 8 = \frac{1600}{18} + 8 \approx 88.8889 + 8 = 96.8889$
2. **X = 165** (в диапазоне 140–180):  
   $Q = 2 \cdot \sqrt{165 - 140} + 42 = 2 \cdot \sqrt{25} + 42 = 2 \cdot 5 + 42 = 52.0000$
3. **X = 200** (больше 180):  
   $Q = 3 \cdot (200 - 180) + 60 = 3 \cdot 20 + 60 = 60 + 60 = 120.0000$
