# Система мониторинга скорости перемешивания(температура пара)
## 📝 Описание проекта
Программа предназначена для мониторинга технологического процесса. Она преобразует измеряемое значение параметра $X$ (скорость перемешивания) в нормированный показатель качества $Q(X)$, проводит оперативный контроль состояния системы (КТ1) и выполняет статистический анализ массива измерений на предмет попадания в заданный допуск (КТ2).

## ⚙️ Входные данные
- **Параметр $X$**: показатель скорости перемешивания (в условных единицах).
- **Диапазон $X$**: любое вещественное число ($X \in \mathbb{R}$).
- **Обоснование корректности формулы на всех участках**:
  1. При $X < 140$ используется квадратичная функция, которая определена для всех вещественных чисел.
  2. При $140 \le X \le 180$ вычисляется квадратный корень из выражения $(X - 160 + 20)$, что математически тождественно $(X - 140)$. Поскольку $X \ge 140$, подкоренное выражение всегда $\ge 0$, и корень извлекается корректно.
  3. При $X > 180$ используется линейная функция, не имеющая математических ограничений.

## 📐 Формула преобразования $Q = f(X)$
Расчёт показателя качества производится по следующей кусочно-заданной функции:

$$
Q(X) = \begin{cases} 
\frac{(X - 140)^2}{18} + 8, & \text{при } X < 140 \\
2 \cdot \sqrt{X - 160 + 20} + 42, & \text{при } 140 \le X \le 180 \\
3 \cdot (X - 180) + 60, & \text{при } X > 180 
\end{cases}
$$

## 🧮 Ручной расчёт (Верификация)
Для проверки корректности алгоритма приведены расчёты для трёх контрольных точек:

1. **$X = 100$** (условие $X < 140$):  
   $Q = \frac{(100 - 140)^2}{18} + 8 = \frac{1600}{18} + 8 \approx 88.8889 + 8 = \mathbf{96.8889}$

2. **$X = 165$** (условие $140 \le X \le 180$):  
   $Q = 2 \cdot \sqrt{165 - 140} + 42 = 2 \cdot \sqrt{25} + 42 = 2 \cdot 5 + 42 = \mathbf{52.0000}$

3. **$X = 200$** (условие $X > 180$):  
   $Q = 3 \cdot (200 - 180) + 60 = 3 \cdot 20 + 60 = 60 + 60 = \mathbf{120.0000}$

## 💻 Структура программы
Код реализован в модульном стиле с соблюдением стандарта C99 и правил CodeStyle:
- `read_temperature` – безопасное чтение входных данных с обработкой ошибок.
- `calc_quality` – расчёт показателя $Q(X)$ с использованием именованных констант (`#define`) вместо магических чисел.
- `control_state` – проверка попадания $Q$ в допустимый диапазон (возвращает код состояния).
- `print_result` – форматированный вывод результатов пользователю.
- `calculate_statistics` – обработка массива значений, подсчёт количества попаданий в интервал и вычисление процента.
